## DESIGN SPECIFICATIONS

### Color Palette
- Primary:    #003087 (Dark Blue)
- Accent:     #FF6600 (Orange)
- Background: #FFFFFF / #F8F9FA (Light Gray)
- Success:    #28A745 (Green)
- Warning:    #FFC107 (Amber)
- Danger:     #DC3545 (Red)

### Typography
- Font Family: Inter (Google Fonts)
- Headings: Bold, #003087
- Body: Regular, #333333
- Small/Meta: Regular, #6C757D

### Framework
- Bootstrap 5
- Card-based layout
- Responsive: Desktop / Tablet / Mobile

### User Roles
1. Người đọc (Reader) - Public access
2. Cộng tác viên (Contributor) - Submit articles
3. Biên tập viên (Editor) - Review & approve articles
4. Quản trị viên (Administrator) - Full system access
